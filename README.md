# Let Me Know

> Asistente de recordatorios por voz para adultos y adultos mayores

[![Flutter](https://img.shields.io/badge/Flutter-3.41+-02569B?logo=flutter)](https://flutter.dev)
[![Dart](https://img.shields.io/badge/Dart-3.11+-0175C2?logo=dart)](https://dart.dev)
[![License](https://img.shields.io/badge/License-MIT-green.svg)](LICENSE)

<p align="center">
  <img src="assets/icons/play_store_512.png" alt="Let Me Know" width="120"/>
</p>

Crea recordatorios hablando naturalmente. La IA detecta patrones, sugiere recurrencias y responde preguntas sobre tus notas por voz.

```
"Tomar pastillas a las 3pm"   → Recordatorio + alarma
"Dejé llaves en la cómoda"    → Nota guardada
"¿Dónde dejé mis llaves?"     → Respuesta por voz
```

## Inicio rápido

```bash
git clone https://github.com/tacuchi/let-me-know.git
cd let-me-know
flutter pub get
flutter run
```
